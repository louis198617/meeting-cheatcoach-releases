# 个人OS：安装说明（试用版）

开线上会议时，它在旁边听，提醒你对方的购买信号、风险和下一步；会后帮你把客户档案整理好。平常帮你记工作时间、看你离目标多远、提醒你该跟进谁。

## 你要先准备

- 一台 Apple 芯片的 Mac（M1 以后的都是）
- Google Chrome（开会要共享会议标签页的声音，只有 Chrome 做得到）
- （建议）Obsidian：免费的笔记软件，到 obsidian.md 下载，建一个 vault。客户档案、会议对话、聊天记录会放进去，能搜、能看关联、能自己改
- 一把 OpenAI API key：到 platform.openai.com/api-keys 建一把，帐号里要先充值（5 美金就能用很久；一小时的会大约 1 美金以内）
- （可选）Claude 订阅 + Claude Code：会后整理、效率分析、会前准备、提案可以改用你的 Claude 额度，不另外付 API 钱

## 第一次安装

1. 下载「PersonalOS-x.x.x-mac.zip」，双击解压
2. 把「个人OS」拖进「应用程序」资料夹
3. 第一次打开，Mac 会说「无法验证开发者」，不给开。这是因为试用版还没有向 Apple 登记，不是病毒：
   - 打开「系统设置 → 隐私与安全性」，拉到最下面，看到「已阻止打开个人OS」→ 按「仍要打开」
   - 再打开一次个人OS，按「打开」
   - 只有第一次要这样
4. 填「第一次设定」：你的名字、生意、卖哪几项服务、自己的项目、API key、资料放哪里（有装 Obsidian 的话，直接选你的 vault）→ 按「开始用」
5. **开「屏幕录制」权限**（记工作时间要用）：系统设置 → 隐私与安全性 → 屏幕与系统录音 → 打开「个人OS」，Mac 叫你重开就重开
6. 如果问「个人OS 想控制 Google Chrome」→ 按「允许」
7. 在 Dock 的个人OS 图标按右键 → 选项 → 保留在程序坞中

## 从 0.1.0（旧名「会议教练」）更新过来

1. 下载新的 zip、解压，把「个人OS」拖进「应用程序」
2. **把旧的「会议教练」App 丢进废纸篓**，Dock 上旧的图标也拿掉
3. 你的客户资料、设定、API key 都会自动沿用，不用重填
4. 照上面第 5、6、7 步开权限、放进 Dock（App 换了名字，Mac 要重新允许一次）

## 每天用

- 点 Dock 上的「个人OS」：主画面、透明浮层都会开好
- **今天**：今天要做的事、会议、目标、时间 · 效率、效率教练（直接问它「今天为什么这么乱？」）
- **客户**：每个客户谈到哪（初聊 → 方向厘清 → 方案报价 → 成交）；点进去有「跟进讯息」「模拟客户」「会前准备」「提案 + 报价」
- **事项 / 伙伴**：要做的事、合作伙伴
- **开会**：在「客户」页点「开会」→ 按「开始听」→ Chrome 问共享哪个画面时，选会议那个标签页，**勾上「同时分享标签页音频」**
- **Log**：AI 和你改过的每一件事，可以撤销
- 右上角的绿色 ⏸：暂停 / 继续记录工作时间

## 让 Claude 帮你操作（可选）

装了 Claude Desktop 的话：菜单栏「OS → 连接 Claude」，在 Claude 里按「安装」。
之后在 Claude 对话框左下角「+」→「个人OS」，有现成的指令：开工、会前准备、跟进讯息、模拟客户练习、收工回顾、这星期检讨、成交检讨、把这段对话存进个人OS。
Claude 只能用个人OS 开放的功能，改不到程序，也看不到你的 API key；客户档案的改动一定先给你看、你说好才写。

## 更新

打开个人OS 时，它会自己检查有没有新版本。有的话会问你要不要下载：下载、解压，把新的拖进「应用程序」取代旧的就好。你的客户资料和设定都不会动。

## 你的资料在哪里

- 客户资料：你在设定里选的 Obsidian vault 里的「个人OS」资料夹（没装 Obsidian 就是「文稿 / 个人OS资料」），都是普通文字档
- 只存在你的电脑。整理时，内容会送去 OpenAI（或你的 Claude）处理
- 工作时间记录：每分钟看一次你在用哪个软件和视窗标题；网银、付款只记「私人」、影片游戏只记「娱乐」，不记内容；截图只拿去判断，不存
- 开发者看不到你的任何资料
