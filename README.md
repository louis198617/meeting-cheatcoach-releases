# 会议教练：安装说明（试用版）

开线上会议时，它在旁边听，提醒你对方的购买信号、风险和下一步；会后帮你把客户档案整理好。

## 你要先准备

- 一台 Apple 芯片的 Mac（M1 以后的都是）
- Google Chrome（开会要共享会议标签页的声音，只有 Chrome 做得到）
- 一把 OpenAI API key：到 platform.openai.com/api-keys 建一把，帐号里要先充值（5 美金就能用很久；一小时的会大约 1 美金以内）

## 安装

1. 下载「会议教练-x.x.x-mac.zip」，双击解压
2. 把「会议教练」拖进「应用程序」资料夹
3. 第一次打开，Mac 会说「无法验证开发者」，不给开。这是因为试用版还没有向 Apple 登记，不是病毒：
   - 打开「系统设置 → 隐私与安全性」，拉到最下面，看到「已阻止打开会议教练」→ 按「仍要打开」
   - 再打开一次会议教练，按「打开」
   - 只有第一次要这样
4. 填「第一次设定」：你的名字、生意、卖哪几项服务、API key、资料放哪里 → 按「开始用」

## 每天用

- 点 Dock 上的图标：主画面、透明浮层都会开好
- 右上角菜单栏的「教练」：调浮层位置、改设定、检查新版本、退出
- 开会：在「客户」页点客户卡片上的「开会」→ 按「开始听」→ Chrome 问共享哪个画面时，选会议那个标签页，**勾上「同时分享标签页音频」**

## 让 Claude 帮你操作（可选）

装了 Claude Desktop 的话：菜单栏「教练 → 连接 Claude」，在 Claude 里按「安装」。
之后可以直接跟 Claude 讲：「帮我看陈老板上次聊到哪」「把这段 WhatsApp 整理进 Amy 的档案」。
Claude 只能用会议教练开放的功能，改不到程序，也看不到你的 API key；客户档案的改动一定先给你看、你说好才写。

## 更新

打开会议教练时，它会自己检查有没有新版本。有的话会问你要不要下载：下载、解压，把新的拖进「应用程序」取代旧的就好。你的客户资料和设定都不会动。

## 你的资料在哪里

- 客户资料：你在设定里选的资料夹（默认是「文稿 / 会议教练资料」），都是普通文字档，可以自己打开、备份
- 只存在你的电脑。整理时，内容会送去 OpenAI 处理（用你自己的 key）
- 开发者看不到你的任何资料
